# 第三轮本地研究协议

制定日期：2026-11-06，正式训练前保存。沿用第二轮依赖和已审计特征；旧目录保持不变。研究对象为具体预测方案，MoLFormer 始终冻结。本轮属于探索性后续研究；新划分不是从未接触过的外部数据。

## 要回答的问题与反例

1. 传统方法的优势是否依赖所用表征？增加 ECFP count＋RF；RDKit 与 MoLFormer 各自比较 Ridge/MLP。若换表征或头改变排序，不将结果概括成模型类别的胜负。
2. 排名是否跨划分维持？两数据集、两种组划分、各三个新划分种子。若排名翻转，报告配对差值及范围，收窄结论。
3. 少标签下的趋势是否跨任务维持？在 Lipophilicity 复核与 ESOL 相同的比例和抽样种子。允许相反趋势。
4. 先前 GNN 的上限是否影响结果？固定第二轮选中的学习率，从相同种子重新训练，保存 300 轮以内的最佳模型与最多 450 轮模型，依验证早停；不按测试结果继续延长。
5. 可选：RDKit 与冻结语言特征拼接是否优于单独表征？仅超过 LM 不算证明互补优势。

## 数据与划分

- 使用第二轮 samples.csv、RDKit2D 与冻结 MoLFormer 特征，按 ID 核对并记录 SHA256。ECFP 采用 RDKit Morgan 半径 2、2048 维 hashed count，输入无立体 connectivity，includeChirality=False；不是 bit 指纹，也不是 count-simulation bit 向量。
- 旧锚点与小样本沿用原划分。C 子集种子为 100/101/102，按连接结构组随机排列，取达到目标样本数的嵌套前缀；同组不拆。验证和测试不变。100% 端点取第二轮 seed 0，ECFP 取 A 的 seed 0。
- B 划分种子 3101/3102/3103。RandomGroup 按 connectivity 分组，RandomScaffold 按既有无立体 Bemis–Murcko scaffold 分组。空骨架 __ACYCLIC__ 保持为同一组。
- 分组算法：大于 10% 总样本数的组固定放训练集（避免单个大组吞掉验证/测试）；其他组按排序后的组键和种子随机打乱；先按不超过 floor(10% N) 的规则装入测试，再装验证，剩余全部训练。无标签参与分组，记录实际比例、大组数和标签分布。不为了得到好看的标签分布重新抽样。
- 每种划分三个测试 ID 集必须不同；检查 connectivity 不跨分区，Scaffold 另查骨架不跨分区。B 与旧确定性 Scaffold 的选择机制不同，不能把旧结果混入 B 的均值/标准差。
- 检索范围包含项目说明、Topics.pptx 已核查记录及本地 DSC6020 课程笔记/检索文本。未发现本组已批准的 molecular benchmark/folds，不能把本协议称为老师要求。

## 模型、选参与训练

- RF 与 ECFP-RF：200 棵树，沿用三个候选 (max_features=1.0,min_samples_leaf=1)、(0.5,1)、(1.0,2)。不同维度导致绝对候选特征数不同，不能声称计算预算完全相同。
- Ridge：alpha 1/10/100/1000/1e4/1e5/1e6；初始最优落上界时仅延伸 1e7/1e8 一次，保留最终边界标记。
- MLP：输入→128→1，ReLU、dropout 0.1；lr 0.001/0.0003，weight_decay 1e-4，batch 64，max 300，patience 40。RDKit 加训练期中位数填补，所有输入缩放和目标缩放只拟合相应训练子集。相同隐藏结构不等于参数量相同。
- D-MPNN：Chemprop 2.2.1 组件、宽度128、深度3、mean aggregation、dropout0.1；lr0.001/0.0003，weight_decay1e-5，batch64，patience30。B/C 按 v2 规则：150轮，若 best_epoch≥130 则保留优化器状态最多到300；边界问题记录而不临时追试。
- D 预算实验只用旧 Random 的 lr0.0003，各种子从头训练。150→300 规则不变；到300且 best_epoch≥270 时允许同优化器继续到450。到300保存“300以内最佳”检查点；提前停止者同一个模型作为两种预算端点。全部种子都报告，不挑先前成绩好的一次。
- 候选只计算验证 RMSE。A 用 seed0 选配置，再固定配置训练1/2；其余阶段 train seed0，D 为固定参数的0/1/2。选择后才导出选中模型测试预测。所有预定候选和失败记录保留。
- 拼接采用 RDKit 210维与 MoLFormer 768维，分别通过统一训练期填补/标准化后的 Ridge；两个分量同一 alpha，公开维度/正则差异。比较整个适配方案，不声称测出了纯粹的语义信息量。

## 核验与解释

每阶段核验输入哈希、划分组隔离、子集嵌套、参数选择、缩放来源、checkpoint 重载和 RMSE/MAE 复算。保留逐分子预测、每轮曲线、时间和签名。核心训练源码、协议和计划变化后拒绝覆盖已有完成任务。

跨划分报告每个划分的配对差值、均值和样本标准差，不将三个划分当成大样本显著性证据；不同划分测试集有重叠。小样本波动只代表抽样，固定验证标签预算另列。可选拼接比较同时呈现两个单独表征，不用测试分数选择“最有利参照”。

本轮不会提出新架构、微调 MoLFormer、加入分类数据集或泛化到通用聊天 LLM。论文与第二轮解读沿用已有已核实文献记录，下一版报告明确哪些观察重复、哪些被推翻、哪些仍不确定。
