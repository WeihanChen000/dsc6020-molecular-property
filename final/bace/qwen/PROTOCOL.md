# 冻结 Qwen3-1.7B 预测 BACE 活性

本次在已有相似组划分上增加通用语言模型。两个编码器读取相同的无手性规范 SMILES，共 1,503 条记录；1,053 条训练、150 条验证、300 条测试。旧模型成绩已经公开，这次属于追加对照。

采用 Qwen/Qwen3-1.7B（版本 70d244cc86ccca08cf5af4e1e306ecf908b1ad5e），用原生 tokenizer 读取 SMILES，不加聊天模板和特殊 token，不截断。模型只做前向计算，在最后一层对有效 token 等权平均，得到每个分子的向量。GPU 以 BF16 计算，向量用 float32 存盘。序列按长度排序，每批 8 条。测量同步后的加载与编码时间、PyTorch 峰值显存和整卡显存，另记 CPU 回归头耗时。下载和环境准备另算。

回归头沿用旧 MoLFormer 实验的 128 隐藏单元 MLP、训练集标准化、批大小 64、Adam、300 轮上限和 40 轮早停耐心。用种子 0 在两个学习率（0.001、0.0003）中按验证 RMSE 选低者，再以种子 1、2 重训；两条路线均报告三个种子全部成绩。缓存输入维度不同，回归头参数量各自报告。以相同测试 ID 对比 RMSE、MAE 和骨架等权 RMSE。只试这一种池化方式，不做 QLoRA，不根据测试结果重选方案。
