# 在 BACE-1 活性预测上检验原结论

2026-11-06。此协议与分区成员表在拟合模型、查看本任务测试成绩前固定。先前的亲脂性实验中，D-MPNN 在三个骨架划分、三个训练种子上均优于冻结 MoLFormer + MLP。本次提出一个可能失败的预测：面对训练中未出现过的 BACE 骨架，D-MPNN 的误差仍会更低。

**任务与范围。** 使用 DeepChem 的 BACE 回归 CSV，目标是实验 pIC50。输入只取 mol 列，Class、Model、已有描述符等列均不进模型。两条路线都从本任务训练标签重新学习预测器。这里只验证模型比较能否迁移到另一种性质。原研究的实验设计与此处不同。[数据说明](https://deepchem.readthedocs.io/en/latest/api_reference/moleculenet.html#deepchem.molnet.load_bace_regression) · [原研究](https://doi.org/10.1021/acs.jcim.6b00290)

**选择依据。** 比较候选时只核对结构。按不含立体信息的规范 SMILES 对照旧 ESOL 和 Lipophilicity，FreeSolv 排除重叠后剩 270/642 条；BACE 剩 1,503/1,513 条。BACE 原文件 SHA256 为 f3fb9ce90bada3e2bd6148b0df13f8f8145a357bf87df0dd5b391ede974fc737。保留同连接结构的多条实验记录，整组分到同一区。旧任务同骨架但连接结构不同的分子不排除。无法核实大规模无标签预训练语料与这些结构的覆盖关系。

**一次锁定测试。** 按无手性 Murcko 骨架分组，空骨架共用一个键。组键排序后用 NumPy default_rng(7101) 打乱，依次把装得下的整组放入测试集（最多 floor(0.20N) 条），再放入验证集（最多 floor(0.10N) 条），剩余训练。不用标签分层，不重抽。额外测试数据量是为了观察更多留出骨架。三个训练种子使用同一份分区。只在两条路线的所有检查点选择完成后解封测试标签。

**训练预算。** 沿用第三轮 CPU 训练器、指纹以外的原图和冻结向量流程。D-MPNN 隐层 128、深度 3、均值聚合、早停耐心 30；150 轮时若最佳轮次至少为 130 则最多延至 300 轮。MoLFormer 使用固定的 IBM 10% checkpoint，取冻结的 pooled embedding，仅训练 128 单元 MLP，最多 300 轮，早停耐心 40。原批大小 64、梯度裁剪、Adam 和正则等按已存 protocol.json。每条路线用种子 0 各试 0.001、0.0003 两种学习率，按验证 RMSE 取低者，平手取第一项。复用胜出的种子 0 检查点，再以种子 1、2 各训练一次。合计 8 次拟合，最终 6 个模型。所有选择只看训练和验证集。本地 CPU；若遇未知 token 或超出原模型预训练长度则记录并披露，保留完整分子序列，不按测试表现调整输入或预算。

**判定。** 主指标为测试记录等权 RMSE，第二指标为骨架等权 RMSE（先算各骨架内 MSE，再对骨架平均并开方）。辅助报告 MAE、逐分子绝对误差胜负、只输出训练均值的基线。只有 D-MPNN 在三个种子、两种 RMSE 下全部严格更低，且均优于均值基线，才称“亲脂性上观察到的优势在本次 BACE 留出集得到支持”。若 MoLFormer 对称地满足，记为方向相反；其他情况记为未稳定复现。数值相等视为平手。报告所有结果，不追加试验。单个测试集和不同训练种子只支持这次模型配置与划分；该检验不能证明所有分子性质的普遍排名。
