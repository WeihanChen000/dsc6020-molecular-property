# BACE 相似分组实验

上次骨架划分的 300 条测试记录中，258 条在训练集有相似度至少 0.6 的近邻。我们预期去掉这些近邻后，冻结 MoLFormer + MLP 在 BACE 上仍比 D-MPNN 更准。旧划分的成绩已知，本次只检验同一数据集换一种留出方式后的排名。

**划分。** 沿用原来 1,503 条记录、无手性连接结构和半径 2、2,048 位的 Morgan 位指纹。如果两条记录有相同 Murcko 骨架，或 Tanimoto 相似度至少为 0.6，就连一条边。用连通分量分组，间接相连的分子也在同组。选阈值时仅检查了 0.60、0.65、0.70 下的组大小。0.60 沿用上轮分档界线，也是三个可选值中约束最严格的。固定种子 8101 打乱组的顺序，依次整组装入测试集、验证集，剩余组用于训练。各区容量及成员见同次提交的 partitions.csv。两种模型共用此划分。禁止按标签、成绩或种子重抽。

**训练。** 复用旧 BACE 的输入、CPU 训练器、编码器与预算。D-MPNN 从头训练，隐层 128、深度 3、最多 150 轮，第 150 轮时若最佳轮次至少为 130 才延至最多 300 轮，早停耐心 30。固定 MoLFormer 编码器，复用逐分子计算的 768 维向量，从头训练 128 单元回归头，最多 300 轮，早停耐心 40。两者批大小均为 64。各模型用种子 0 尝试学习率 0.001、0.0003，按验证 RMSE 选低者，平手选第一项。固定入选学习率，再训练种子 1、2。共八次拟合，六个入选模型。缩放器与目标均值仅用新训练集拟合。完成两条路线的验证选参后才计算新测试集成绩。

**如何判断。** 分别报告两个划分的测试到训练最近邻相似度均值、中位数、最大值及原三档计数；同一性质内比较 RMSE 和 MAE。三种种子下，如果冻结 MoLFormer 的按记录 RMSE 和按 Murcko 骨架等权 RMSE 都严格低于 D-MPNN 和训练均值，记为保持排名；D-MPNN 对称满足则记为反转；其他结果记为混合。保留所有种子，不再扩大训练预算。另报告测试连通组大小、新旧测试记录重叠和标签分布，说明成员变化与结构距离同时发生。这些分数差只作描述，三种种子共用一批测试记录。
