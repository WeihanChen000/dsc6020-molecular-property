# 只用明确 IC50 的训练与验证记录

原相似组划分不动，按上轮标签清单中的 `exact_ic50` 取子集，固定训练 992 条、验证 147 条、测试 268 条。这个字段要求作者记录的测量类型为 IC50、关系符为等号，并能用原始浓度与单位核对对数标签。拟合和评分使用原数据集的对数标签。旧模型在这 268 条上的成绩已经公开。

主问题是冻结 Qwen 的逐分子 RMSE 能否在种子 0、1、2 中每次都严格低于冻结 MoLFormer 和 D-MPNN。三个模型复用相同的分区和旧训练器。Qwen、MoLFormer 分别复用已归档的 2,048 维和 768 维冻结向量，从头训练 128 单元的 MLP；D-MPNN 从头训练，隐藏宽度 128、深度 3。缩放器和目标均值只用这 992 条训练记录拟合。

每条路线先用种子 0 比较学习率 0.001 和 0.0003，以 147 条验证记录的最低 RMSE 选学习率和检查点，平手取先列者。种子 1、2 沿用入选学习率，各自用验证集早停。批大小 64。MLP 最多 300 轮、耐心 40；D-MPNN 最多 150 轮、耐心 30，仅当第 150 轮时最佳轮次至少为 130 才延至最多 300 轮。共 12 次拟合，9 个入选模型。沿用本机 CPU 四线程环境，预计数分钟完成，无需重新编码分子。

三条路线都完成验证选参并保存记录后，才重载模型评分。逐种子报告同一批 268 条测试记录的 RMSE、MAE 和骨架等权 RMSE（先在每种骨架内平均平方误差，再跨骨架平均并开方）。以原混合标签训练模型在这 268 条的既有成绩作配对对照，保留所有结果。不会因测试排名追加训练。训练、验证两组的样本组成和数量都随筛选而变，本实验只检验这套筛选及选参做法下的排名。
