# FreeSolv 水合自由能实验协议

用完整 642 条记录单独训练和评分，标签取 SAMPL.csv 的实验值 expt，单位 kcal/mol。输入只取 SMILES。此前按连接结构与 ESOL、Lipophilicity 核对，排除重叠后只剩 270 条。本次检验换性质后的新任务，允许任务间结构重合。各任务的监督标签、缩放器和回归模型分别拟合。

在看本轮测试成绩前写下问题。D-MPNN 在亲脂性骨架划分上的优势，能否延续到水合自由能？如三个骨架划分在三次训练下均由 D-MPNN 取得更低的分子等权 RMSE，记为方向一致。另报 MAE、骨架等权 RMSE 和逐批结果，接受排序改变。

沿用 study-v3 的 grouped_split 和划分种子 3101、3102、3103。分别按无手性规范连接结构和 Murcko 骨架分组，无环统一一组。验证、测试目标各 64 条，超过容量的组留在训练，允许整组放置剩余少量空位。先保存所有成员；报告各批记录数、骨架数、实际覆盖、重叠与不可留出的大组。

四条路线共用训练、验证、测试 ID。均值基线只读训练标签。RDKit 全描述符 + 200 棵树 RF 沿用 v3 三档参数。Chemprop D-MPNN 和冻结 MoLFormer（10pct 固定版本、pooler_output）+ 128 单元 MLP 各试学习率 0.001、0.0003。只按种子 0 的验证 RMSE 选参，并列取第一档。组随机只跑种子 0。骨架划分另用同一组选定参数独立拟合种子 1、2。沿用 v3 标准化和早停，D-MPNN 150 轮、耐心 30，第 150 轮最佳轮次达到 130 时自动放宽至 300；MLP 最多 300 轮、耐心 40。6 × 7 + 3 × 6 = 60 次候选或重复拟合。预计本机 CPU 数分钟至约半小时，无需云端。选定后重载检查点，核对验证分数，再算测试预测。记录冻结向量提取和各路线拟合耗时。
