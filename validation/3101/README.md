## 候选怎么选

RF 与 D-MPNN 的验证成绩来自已核验的旧基线。本轮每份划分新增 2 个 MoLFormer 和 6 个 Qwen 候选。每个候选最多 20 轮，连续 10 轮验证 RMSE 未改善就停。每个模型取正常完成者中验证 RMSE 最低的候选及轮次，完全持平时取预定顺序靠前的候选。

- **MoLFormer** 联合训练编码器与回归头，M1、M2 的学习率分别为 3e-5、1e-4。六份划分最终都采用 M1，其中五份有两个正常完成的候选。
- **Qwen3-1.7B** 冻结 4-bit 基座，训练 LoRA 与回归头。Q1 取有效 token 均值，学习率 1e-4，rank/alpha 为 8/16。Q2 只改取最后一个有效 token。Q3、Q4、Q5 分别把 rank/alpha 改为 16/16、8/32、16/32。Q6 只把学习率改为 3e-5。[候选配置和每份划分的记录数](protocol.json)

**唯一失败的候选是 Lipophilicity Scaffold 的 M2。** 首次在第 16 轮触发零梯度检查；同种子、同参数复跑后，在这一轮第 166 次更新前测得编码器梯度范数为 0、回归头为 1.3267。失败前最佳验证 RMSE 是第 11 轮的 1.2067，仅供诊断。候选表在 status 列标记了这项失败。[全部候选的成绩、状态和耗时](candidates.csv)
